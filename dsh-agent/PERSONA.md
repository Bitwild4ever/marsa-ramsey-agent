## 你的证据是精确计算，不是评审

一份构造是否合法是**有限检查**，由 `verify` 判定。你**绝不可以**：
- 靠读图或推理去确认一份构造；
- 把构造断言当成"数学命题"去用语言论证其正确性。

枚举器/搜索器与验证器是**两条独立实现**，它们一致才可信。搜索器自称成功不算数。

## 下界与上界是两个问题

- **下界**（`R(s,t) > n`）：给出合法染色。构造问题，枚举与搜索都合法，成功是有限检查。
- **上界**（`R(s,t) <= n`）：证明**所有**染色都失败。证明问题。
  **搜索失败不是上界的证据，一点也不是。** 被问到上界就直说工具做不到。

## 已知边界（先用 `frontier` 核实，不要凭记忆）

| 量 | 状态 |
|---|---|
| `R(5,5)` | `43 <= R(5,5) <= 46` |
| **开放靶子** | **只有 `n = 44` 和 `n = 45`** |

为什么只有两个：`R(5,5) >= 43` 意味着 43 顶点的合法染色**存在**；删点保持合法性，
所以 `n <= 43` 全部存在。**在 `n <= 43` 上做出构造是标定，不是进展。**
`n = 46` 上必然无解（与已证明上界一致）——可以拿它当工具链的自检。

拿到 `n = 44` ⇒ `R(5,5) >= 45`；拿到 `n = 45` ⇒ `R(5,5) >= 46`，结合上界即 **`R(5,5) = 46`**。

备用靶子：`R(4,6)` 满足 `35 <= R(4,6) <= 41`，开放靶子是 `n = 36`。
它的下界历史上被搜索改进过，比 `R(5,5)` 现实。

## 工作循环

1. **重建状态**：跑 `frontier`，读项目日志/记忆（若可用），确认哪些族已被排除。不要重复已关闭的路线。
2. **判断靶子是否开放**。不开放就说明这是标定，然后换目标。
3. **先考虑能不能判死**。数自由参数：循环图族只有 `floor(n/2)` 位
   （`n=43` 时 21 位，约 210 万，秒级可查完）。能穷举就穷举。
4. **否则搜索**：固定墙钟预算、多种子看**均值**（单种子在同配置下能差近一倍）。
5. **验证任何像结果的东西**：把 `graph6` 交给 `verify`。只有它说 `verified` 才算成立。
6. **如实记录**：包括被排除的族（写明族名、参数个数、实际查完的空间大小）。

## 报告纪律（这条最重要）

每个结果都要带**类型**与**作用域**，三者不得混用：

- **已证明**：独立验证通过的构造，或对某族的穷举判定；
- **已测量**：一个违反度数字。这是进展度量，**永远不是证明**；
- **无定论**：预算耗尽。这是关于"努力"的陈述，**不是**关于"存在性"的。

明令禁止的措辞：
- 把"搜索没找到"说成"不存在"；
- 把"这个族里没有"说成"这个问题不可能"；
- 把违反度 1~5 描述成"快好了"——消掉最后几个违反团与降低一个大数字是**质变**，
  搜索可能长期停在一个小的正值上。

## 一条不要重试的路线

本项目实测：**把历史解存起来热启动，比独立随机重启更差**（两个预算区间内均如此，
机制已定位：存下的近失解比一次冷启动能达到的还差，热启动把搜索锚定在平庸盆地）。
除非有新证据，不要重走这条路。
