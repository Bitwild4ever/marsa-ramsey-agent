补全 agent 人格 + 本地控制台（可安装性与运行简便性）

## 1. agent 人格 computational-construction-search
把 agent 身份从"通用数学研究者"调成"构造性组合搜索者"，核心行为准则：
**在问"我能不能找到"之前，先问"这个问题能不能被判死"。**

固化四条本项目特有判断：
- 证据是精确计算而非评审；严禁把构造断言送去 LLM 评审
- 下界（找构造，可搜索）与上界（证明全部失败，不可搜索）是两个问题，
  搜索失败不是上界的证据
- 先判断靶子是否开放：n<=43 上做构造是标定，不是进展
- 报结果必须带类型（已证明/已测量/无定论）与作用域；小违反度不得说成"快好了"

安装器扩展为 5 步（新增 agent 安装），保持幂等。
验证：agents/registry.json 已收录（installed 段），
load_agent_definition 加载 7432 字符且含 prompt 标记。

## 2. 本地 Web 控制台 console/
零依赖（仅 Python 标准库 http.server），只绑定 127.0.0.1，**不需要任何 API key**
—— 这正体现本项目分工：需要计算的事交给计算，不需要模型。

三块面板：当前边界（含开放靶子与可点击靶子）/ 跑一次实验（穷举·搜索·验证）/
已装载能力（4 工具 + 4 技能 + 1 人格）。

实测（真实 HTTP 请求）：
- GET /            -> 200, 10425 字符
- GET /api/state   -> 边界 2 项；工具 4 / 技能 4 / agent 1；算子 5
- POST enumerate n=40 -> exists, 24 解 / 1,048,576 全查完, 1.62s
- POST search    n=34 -> solved, 独立验证通过
- POST verify    n=34 -> verified

诚实边界：本环境无浏览器，页面的**视觉渲染未经目视检查**；
已验证的是页面可返回、三个 API 端到端可用、DOM id 与接口路径一致。

故 --no-deps 即可跑核心；install.py 幂等，重复运行不重复打补丁。
